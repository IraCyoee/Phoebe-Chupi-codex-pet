# 菲比 Codex 桌宠

给 Codex 桌面版准备的两只菲比桌宠：**菲比·蹦一下**和**菲比·坐好了**。动作灵感来自 `鸣潮·致予新世界动态表情包` 中菲比的「坐好了」表情包。

## 动作预览

| :---: | :---: | :---: | :---: |
| 菲比·蹦一下 | ![菲比·蹦一下的坐姿常态](assets/original-idle.webp) | ![菲比·蹦一下起身跳跃](assets/original-hover.webp) | ![菲比·蹦一下的工作动作](assets/original-coding.webp) |
| 菲比·坐好了 | ![菲比·坐好了眨眼、歪头](assets/storyboard-idle.webp) | ![菲比·坐好了坐姿回应悬停](assets/storyboard-hover.webp) | ![菲比·坐好了坐着敲电脑](assets/storyboard-coding.webp) |

「坐好了」在常态、悬停和工作时保持坐姿；「蹦一下」悬停时会起身跳。左右拖动的奔跑动作在两个版本中相同。

## 安装

在仓库根目录运行。只装一个版本的话，运行对应的 `cp` 命令即可。

```bash
mkdir -p ~/.codex/pets
cp -R pets/phoebe-evidence ~/.codex/pets/
cp -R pets/phoebe-storyboard ~/.codex/pets/
```

然后在 Codex 的宠物选择界面选择“菲比·蹦一下”或“菲比·坐好了”。两个版本可以同时安装。
